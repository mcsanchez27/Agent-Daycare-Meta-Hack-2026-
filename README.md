# Agent Daycare

One chat window for talking with **Antigravity**, **Claude** and **Codex** on your own PC. A prototype in the Batcave lineage.

**Status:** V1 rebuild in progress (TM-47). The old dashboard (mascots, hooks, roles) was removed; its last version is the git tag `v0-dashboard`.

## Run it
1. Install the three CLIs and make sure each is logged in: `agy`, `claude`, `codex`.
2. `npm install`
3. `npm start` (or double-click `Start-Agent-Daycare.bat` on Windows)

## Test
`npm test`

Notes for AI agents working in this repo are in [AGENTS.md](AGENTS.md).
