# Stitch Prototyping & Design Systems

Institutional playbook for generating high-fidelity UI screens and tokenized components with Stitch.

## Operational Standards
1. **Design System Grounding:** Use MMS Calm Obsidian design tokens (`#131314` base, `#1e1f20` panel, hairline borders).
2. **Screen Isolation:** Save all screen deliverables in `design/` subfolders (`design/*.html`).
3. **Design Notes:** Always write a `design/NOTES.md` explaining tokens, typography, hierarchy, and interaction states.
